# Freshworks (Jan 2020 - Oct 2023)

I spent just under four years at Freshworks in Chennai, India, across three roles, moving from intern to Senior Software Engineer.

## Senior Software Engineer, Backend/Platform Focus (Apr 2023 - Oct 2023)

My stack here was AWS SQS, AWS Lambda, Pinecone, Redis, Grafana, and PostgreSQL. I architected a high-throughput RAG ingestion pipeline using SQS, Lambda, and Pinecone to support the Freddy AI platform, implementing vector-namespace isolation to guarantee secure multi-tenant retrieval across enterprise customers. I served as primary technical lead for the ESM-to-AI integration, delivering a production-ready system during a high-pressure 30-day sprint to meet global launch deadlines. I also designed an operational monitoring and reporting stack using Redis and Grafana, reducing Mean Time to Resolution by 40% through PostgreSQL query optimization and automated incident alerting. Separately, I led an architectural overhaul of the core billing engine to support enterprise-scale ITSM suites, automating high-stakes financial state machines to eliminate 60% of manual interventions; that work was also associated with a 35% acceleration in sales cycles, though the sales-cycle link is the weaker, more indirect claim of the two.

## Software Engineer, Full-Stack (Oct 2020 - Mar 2023)

My stack here was Kafka, RabbitMQ, Sidekiq, PostgreSQL, PgBouncer, AWS (ALB, SQS, Lambda), Redis, CDN, React, and TypeScript. I designed an event-driven engine using Kafka/RabbitMQ and Sidekiq, optimizing background worker pools to process over 1 million daily tasks. I implemented PostgreSQL read-replicas and PgBouncer connection pooling, reducing primary database load by 40% for 4,000+ concurrent SMB customers. I directed zero-downtime data migrations from Google Hire and BambooHR using throttled batch processing and shadow-writes, maintaining 100% data consistency for millions of records. I managed AWS infrastructure (ALB, SQS, Lambda) via automated CI/CD with blue-green deployment patterns, achieving 99.9% uptime and cutting rollback times. I engineered a multi-tier caching strategy with Redis and a CDN to mitigate thundering-herd issues, reducing p99 API response times by 60% during peak login surges. I optimized a data-heavy time-off dashboard with viewport-based batch rendering in React Highcharts, eliminating DOM jitters and reducing initial loading latency by 80%. I also spearheaded the incremental migration of UI components to TypeScript within a React (SSR) codebase, enforcing type-safe component contracts.

## Software Engineer Intern (Jan 2020 - Sep 2020)

My stack here was Dialogflow, Node.js, RSpec, and Cucumber. I designed and prototyped an NLP-based HR chatbot using Dialogflow and Node.js that reduced ticket volume by 40%, which secured 3rd place in the 2020 Freshworks Global Hackathon. I also established RSpec and Cucumber testing standards, increasing unit and functional test coverage from 60% to 90%.

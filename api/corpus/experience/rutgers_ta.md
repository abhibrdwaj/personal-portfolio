# Graduate Assistant at Rutgers University

As a Graduate Assistant at Rutgers University's Department of Computer Science (August 2024 - December 2025), I engineered a robust C++ automated evaluation pipeline for over 500 students, optimizing batch processing to handle 100+ concurrent submission bursts during peak deadline traffic [19]. To guarantee fairness and reliability, I built a deterministic stress-test harness to evaluate algorithm efficiency (O(n) verification) and edge-case stability, which successfully reduced manual regrade requests by 50% [19]. I led CS214 lab sessions, where I mentored students in low-level systems, specifically manual memory management using malloc and free [19]. I guided them in utilizing tools like Valgrind and GDB to resolve complex segmentation faults and memory leaks [19]. In the realm of distributed systems, I designed a multithreaded Network File System (NFS) assignment using POSIX Sockets and Mutex Locking to teach students how to manage concurrent operations effectively in a C client-server environment [19].

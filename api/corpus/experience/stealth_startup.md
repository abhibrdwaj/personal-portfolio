# Founding Engineer at Stealth Healthcare Venture

As a Founding Engineer at a Pre-Seed Stealth Healthcare Venture in New York City (Dec 2025 - Present), I spearheaded a specialized, multi-agent conversational interface using LangGraph [3, 8]. By dynamically routing voice and text inputs to specialized medical agents, I reduced parental logging friction by an estimated 60% while ensuring deterministic, safe AI responses [3]. To support this, I designed a complex multi-vector Retrieval-Augmented Generation (RAG) pipeline querying isolated data domains, which improved contextual retrieval accuracy by 35% for developmental milestone tracking and pediatric risk stratification [9]. On the infrastructure side, I established a secure, multi-tenant deployment architecture utilizing serverless cloud infrastructure on Azure and Vercel, automating CI/CD pipelines to support rapid iteration during early-stage clinical beta testing [10]. I also developed a low-latency API layer using Server-Sent Events (SSE) and WebSockets to stream token-by-token AI responses to the frontend interface, significantly optimizing perceived latency for the voice-activated chat functionality [11].

In my Founding Engineer role, dealing with complex healthcare data required robust processing and safety measures. I engineered a medical entity extraction pipeline and Clinical NLP system to map unstructured parent inputs to standardized clinical terminologies, structuring complex health data to enable precise tracking and Electronic Health Record (EHR) compatibility [9]. Expanding on this, I built automated pipelines that aggregate standardized chat data and Apple HealthKit telemetry into structured Physical Examination Summaries [9]. By utilizing Large Language Models (LLMs) to synthesize weeks of this multi-modal data, I projected a 40% reduction in pediatrician chart review time [9]. To ensure reliability and mitigate model drift, I deployed a comprehensive backend observability and continuous evaluation suite utilizing an LLM-as-a-Judge framework [11]. This automated regression testing across agent reasoning paths allowed me to constantly benchmark against clinical baselines, ensuring the highest standards of safety for healthcare AI applications [11].

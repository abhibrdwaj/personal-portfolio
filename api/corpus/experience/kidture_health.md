# Founding Engineer at Kidture Health

Since January 2026 I've been the founding (and sole) backend engineer at Kidture Health, a pediatric health startup, based in New York with infrastructure in AWS `eu-west-2`. My stack is Python and FastAPI, SQLAlchemy 2.0 with Alembic for migrations (39 shipped, each verified with a full Postgres upgrade-downgrade-upgrade round-trip), PostgreSQL with pgvector, Redis, Docker on Render, and the Anthropic Claude API (Haiku 4.5) for the AI-facing pieces. With no dedicated DevOps, compliance, or DBA function to hand work off to, I own schema design, migrations, the API, compliance work, and deployment end to end.

On data and compliance, I built a GDPR-aligned account-erasure system: an explicit deletion registry over SQLAlchemy's table metadata run in a single transaction (this deployment enforces no foreign keys, so it isn't DB-cascade), with a coverage-guard test that fails CI if any table is left unregistered — shipped as a zero-downtime dual-write migration, verified by 33 new tests with zero regressions against a 1,019-test baseline. I also refactored the core per-child rollup tables into a generalized `(subject_type, subject_id)` schema via a backward-compatible migration, adding 1:N device-metric fan-out at ingest so the platform can support a second product surface without a rewrite — validated against a real-data Postgres round-trip, not just SQLite tests.

On infrastructure, I designed and provisioned a 2-AZ AWS VPC (4 subnets) with app and worker compute never assigned a public IP, a self-managed NAT instance as a deliberate cost trade-off against a managed NAT Gateway, and 6 VPC Gateway/Interface Endpoints routing AWS-service traffic (Bedrock, ECR, CloudWatch Logs, Secrets Manager, S3) instead of through NAT. I tracked down two live-only infrastructure bugs invisible from the console: a VPC endpoint DNS-resolution failure caused by `enableDnsHostnames` defaulting off on a manually-created VPC, and a NAT masquerade rule silently matching zero traffic because Amazon Linux 2023 on Nitro-based instances doesn't default its primary interface to `eth0`. I provisioned RDS PostgreSQL (pgvector-enabled) and ElastiCache Serverless in private subnets, choosing the Valkey engine over Redis OSS specifically for cost — Redis OSS Serverless's 1GB floor prices around $91/month before any real traffic, versus Valkey's 100MB floor at roughly $6/month. I also ran a 12-gap compliance register against a signed Data Protection Impact Assessment and turned it into a scoped, sequenced AWS migration plan targeting a right-sized run cost of about $50-65/month rather than defaulting to production-scale sizing. I also designed a per-moment Redis-queued worker lane plus an hourly cron lane, deployed as separate Dockerized Render services with atomic-deploy semantics enforced at the infra level — worker and cron ship together or ingestion halts entirely — verified with a 656-test regression suite that closed 14 pre-existing failures with zero new ones.

On the AI and clinical side, I designed a deny-list-based safety redirect layer, enforced entirely in application code ahead of any model call, that escalates potentially acute symptoms without the escalation decision ever being LLM-generated — a hard architectural boundary, not a prompt instruction, verified by a dedicated test suite asserting the LLM is never invoked on that path. I built a hybrid clinical-term resolver: a zero-LLM curated catalog for common symptoms, batched into a single Claude Haiku 4.5 call per request for free-text extraction where the model only proposes concepts and never assigns codes, resolved against the NLM UMLS API through an exact-to-normalized-to-fuzzy match ladder with two-tier caching. Running a golden-dataset eval against the live API surfaced two production-only integration bugs invisible to mocked tests, and raised code-assignment accuracy from failing to 75% after the fix. I also built a two-tier pattern-insight engine where a rules layer (day-frequency ranking, then significance tests) gates whether a pattern surfaces at all — Claude is only ever called to phrase a sentence from already-validated structured fields, keeping fuzzy reasoning out of the detection path entirely. Beyond that, I built an NLP extraction service converting free-text caregiver input into typed, schema-validated clinical observations with explicit confidence weighting, and an async pipeline turning coded observations into a physician-facing PDF via WeasyPrint, with its own Postgres-backed expiry/purge handling. I also shipped and hardened device-integration sync for Oura and Apple HealthKit, including a production resilience fix for sync-state drift.

On engineering discipline, I use structlog-based structured logging across every service, every one of the 39 Alembic migrations is verified via a full Postgres round-trip, and every regression suite is diffed test-name-by-test-name (not just pass/fail counts) against a recorded baseline in GitHub Actions CI. For anything backed by the Claude API, I built a uniform stub-mode pattern — the absence of an API key triggers a deterministic code path — so the full pytest suite gets network-free, reproducible coverage of otherwise non-deterministic AI pipelines. Across roughly one week of continuous delivery I shipped a connected sequence of systems — the Redis/Docker enrichment architecture, the statistical pattern-insight engine, and the WeasyPrint clinician report pipeline — each verified by a full regression suite with zero silent breakage.
